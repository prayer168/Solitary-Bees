# 🔍 放大鏡的秘密 · 凸透鏡成像實驗

一份適合**國小中高年級（可延伸至國中理化）**的自然科互動數位教材。
取材自「科學探究與實作影片-05：放大鏡實驗」，帶學生親手操作，找出凸透鏡成像的規律。

線上版（部署後）：`https://prayer168.github.io/Solitary-Bees/lens/`

## 教材簡介

一片小小的放大鏡（凸透鏡），為什麼有時把東西放大、有時卻讓影像上下顛倒？
本教材用科技深色互動風格，透過**可拖曳的光學實驗台**、影片場景重現、探究任務與闖關測驗，
讓學生觀察「倒立／正立、放大／縮小、清楚／模糊」如何隨距離變化，並學會像科學家一樣提問與驗證。

## 適用對象

- 國小中年級、高年級自然科（定性觀察為主）
- 國中理化（可打開「進階」補上焦距 f、2f 與光線追跡原理）
- 教學時間：約 40～80 分鐘
- 裝置：電腦、平板、手機、觸控螢幕、投影機（RWD 響應式、支援拖曳與觸控）

## 核心互動：光學實驗台

- 側視光學導軌：**拖動蠟燭**或用滑桿改變物距，即時重算成像。
- 畫出三條主要光線（平行光→焦點、過鏡心、過焦點→平行）與成像位置。
- 即時判讀：倒立／正立、放大／縮小／等大、實像／虛像、能否投影、物距與像距、放大率。
- 焦點附近顯示「無法成像（模糊）」；物距 < 焦距時畫出正立放大的虛像（含虛線回推）。
- **一鍵重現影片場景**：遠處倒立縮小、2 倍焦距等大、靠近倒立放大、焦點模糊、很近正立放大。
- **進階模式**：可調整焦距 f，直接回答影片「不同放大鏡結果會不會一樣」的提問。

## 使用方式

1. **直接開啟**：用瀏覽器打開 `lens/index.html` 即可（純前端、可離線）。
2. **本機預覽**：
   ```bash
   python -m http.server 8200
   # 開啟 http://localhost:8200/lens/
   ```
3. **部署到 GitHub Pages**：推上 `main` 後，於 `https://prayer168.github.io/Solitary-Bees/lens/` 開啟。
