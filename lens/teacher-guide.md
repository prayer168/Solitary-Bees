# 教師教學指引｜放大鏡的秘密 · 凸透鏡成像實驗

本教材取材自「科學探究與實作影片-05：放大鏡實驗」，設計成可投影導入、可分組操作、也可學生自學。

## 一、對應概念

- 放大鏡＝凸透鏡，能使光線會聚成像。
- 物體到透鏡的距離（物距）決定像的性質：
  - 物距 > 2f：倒立、縮小、實像
  - 物距 = 2f：倒立、等大、實像
  - f < 物距 < 2f：倒立、放大、實像
  - 物距 = f：無法成像（模糊）
  - 物距 < f：正立、放大、虛像（放大鏡看字的情形）
- 核心規律：物體由遠到近 → 倒立縮小 → 倒立放大 →（焦點瞬間模糊）→ 正立放大。

## 二、建議教學流程（約 40～80 分鐘）

1. **導入（5 分）**：用「🏠 開始」「🎯 學習目標」引起動機，提問：放大鏡為什麼有時會讓影像顛倒？
2. **認識器材（5 分）**：「🧰 實驗器材」點選各器材；強調用火安全。
3. **看示範（10 分）**：「🔬 實驗示範」對照影片三步驟與 20/40/60cm 數據，帶出「重要發現」流程圖。
4. **動手探究（15～30 分）**：分組操作「🔭 光學實驗台」，用「一鍵重現影片場景」逐一觀察五種像，並記錄物距。
5. **整理規律（5～10 分）**：對照「📊 成像規律」表；回實驗台拖動蠟燭，觀察表格連動高亮。
6. **探究挑戰（5～10 分）**：完成「🧪 探究挑戰」三個任務，鼓勵先預測再驗證。
7. **收尾檢核（5～10 分）**：以「🏆 闖關測驗」收尾。

## 三、實體實驗安全提醒

- 使用蠟燭與打火機務必有教師陪同，桌面淨空、頭髮衣袖遠離火源，用畢立即熄滅。
- 若不便用明火，可用手電筒或手機燈照亮箭頭圖卡當作「發光物體」替代。

## 四、可延伸討論的問題

- 為什麼物體在焦點上時屏幕會一片模糊？（光線折射後平行、無法會聚）
- 實像和虛像差在哪裡？（實像能被屏幕接住、倒立；虛像不能投影、正立）
- 換一片焦距不同的放大鏡，看到相同性質的像時，物體距離會一樣嗎？（不一樣——打開實驗台「進階」調整焦距驗證）

## 五、差異化教學

- **國小**：以定性觀察為主，聚焦「倒立/正立、放大/縮小、清楚/模糊」與距離的關係，不必談公式。
- **國中**：打開實驗台「進階：焦距的秘密」，引入 f、2f 與光線追跡，連結像距、物距與放大率。
